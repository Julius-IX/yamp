## 4. Data

4.1. The Developer does not collect, store, sell, share, or analyze user data.
The Developer operates no server that receives user data and has no access to it.

4.2. Information accessed by the App is used solely to provide the functionality of the App.
It remains within the user's own accounts with the services listed in Section 3, on the user's own devices, or in data derived from it on those devices.

4.3. **Synchronization.**
If the user links a Google Drive, OneDrive, or iCloud account, the App stores its data in that account in order to synchronize the user's devices.
This data comprises the user's library, playlists, likes, listening statistics, and any app settings the user has chosen to synchronize.
It is stored exclusively in the user's own account.

4.4. **Statistics.**
The App records listening statistics (per day: track title, artist, thumbnail, time listened, and number of plays).
These statistics are kept on the user's device.
They leave the device only if the user has linked a cloud account, and then only to the user's own cloud storage.
The user may disable statistics in the settings of the App.

4.5. **Discord.**
If the user enables Rich Presence, the track title, artist, and cover image are transmitted to Discord through the Discord application on the user's computer for display on the user's profile.
The handling of this information by Discord is governed by Discord's own policies.

4.6. **Revocation and deletion.**
The user may revoke the App's access at any time through the account settings of the respective service (Google, Microsoft, Apple, or Discord).
Data stored by the App in a cloud account may be deleted through the app management settings of that service.
